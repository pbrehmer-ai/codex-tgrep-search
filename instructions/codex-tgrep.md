## Repository text search

Before broad or repeated local repository text searches during coding, debugging, or review, use the `codex-tgrep-search` skill and prefer tgrep when suitable. If it is not listed, read `__SKILL_PATH__` if accessible. Use the configured executable `__TGREP_PATH__` explicitly; PATH is not required. Reuse a suitable index/server, scope discovery, keep output compact, and follow the skill's freshness checks. Read known files directly and use available semantic tools when appropriate. If tgrep or the skill is unavailable, or a higher-priority instruction requires another tool, use a suitable fallback and state a material limitation once. Do not install tools or change permissions during ordinary searches.
